# Limbus Company - Beginner's Overview

> A simple website that provides a general overview of Limbus Company for beginners.

## 📖 About The Project

This project is a lightweight, web-based introductory guide designed to help new players understand the basics of **Limbus Company**, a game by Project Moon. It breaks down the dense lore and complex mechanics into easily digestible information for beginners. 

## ✨ Features

* **World & Lore Introduction:** A simplified breakdown of "The City" and the game's main premise.
* **Sinner Profiles:** General overview and basic details for the 12 main characters (Sinners).
* **Gameplay Basics:** Beginner-friendly explanations of core game mechanics.
* **Interactive UI:** Smooth content switching and dynamic interactions powered by JavaScript.

## 🛠️ Built With

* **Backend:** PHP
* **Frontend:** JavaScript, HTML5, CSS3

## 📂 Repository Structure

* `assets/` - Contains all images, icons, and visual media used across the website.
* `index.php` - The main entry point of the application.
* *(Tambahin file/folder utama lain di sini kalau ada, misalnya `style.css` atau folder `includes/`)*

## 🚀 Getting Started

To get a local copy up and running, follow these steps.

### Prerequisites

You will need a local web server environment installed on your machine, such as:
* [XAMPP](https://www.apachefriends.org/index.html)
* [Laragon](https://laragon.org/)
* Or simply use the PHP built-in server.

### Installation

1. Clone the repository:
   ```sh
   git clone [https://github.com/](https://github.com/)[username-github-lu]/[nama-repo-lu].git
   ```
2. Move the project folder to your local server's root directory:
   * For XAMPP: C:/xampp/htdocs/
   * For Laragon: C:/laragon/www/
3. Open your web browser and navigate to:
   ```sh
   http://localhost/limbus
   ```
## 📝 Usage
Simply navigate through the navigation menu to read about the different aspects of the game. The JavaScript functions handle the dynamic loading of character details and tooltips without requiring constant page reloads.
